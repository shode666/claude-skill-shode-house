# 3.16.0-rc.2 — Ask Oliver

Candidate, not a published release. Durable release status: Beads shode-house-5cs.

RC2 narrows continuity loading for already-confirmed standalone review/explanation
and discourages redundant file inventories. RC1's six-trial Codex review benchmark
passed finding quality but failed token-volume regression. RC2's six-trial review
batch confirms the loading correction and finding quality; total-volume median
fell 15.4% against its fresh baseline, but the combined efficiency gate still fails
on uncached-input-plus-output (+3.7%). Small-sample variability is substantial.
See [RC2 evidence](../eval/portable-team/BENCHMARK-RC2-2026-09-11.md).
Three Codex read-only synthetic first-use/checkpoint probes pass; see
[continuity evidence](../eval/portable-team/CONTINUITY-RC2-2026-09-11.md).
A two-process Codex test also passes actual checkpoint write and fresh-session
continuation after a planned clean exit; see
[resume evidence](../eval/portable-team/RESUME-RC2-2026-09-11.md).
Forced-interruption recovery and full host acceptance remain unverified for RC2;
no stable/savings claim.

One entrypoint, `ask`, with Oliver in the main session. Consultation, design,
implementation and review are outcomes; an explicit request can continue the
identified design without another command. Review/design approval does not grant
implementation, commit or deployment authority.

First use confirms project-selected sources of truth. Markdown is the fallback
for tasks, specs, decisions, checkpoints and evidence summaries; remote IDs and
pending synchronization remain explicit. Resume checks actual artifacts and stale
evidence before proceeding; uncertain external effects must not be blindly replayed.

Six Markdown files replace the released legacy workflow surface. References load
by applicability; no runtime scripts, hooks, tracker, interpreter or mandatory team
fan-out. Project tools and host capabilities still constrain execution. This is
instructional coordination, not enforced locks or an autonomous scheduler.

Build with `make pack`; validate with `make validate-portable`. The portable ZIP
and Claude plugin share exact instruction bytes. Default packaging excludes legacy
commands/agents/hooks/output styles. Existing root legacy manifests remain for
migration; do not install this repository root as the new release. Follow
[installation guidance](../docs/portable-team-install.md).

Compatibility and token reduction are not proven by smaller source files or
archive validation. Live four-host acceptance and matched repeated whole-workflow
efficiency/recovery trials are release gates. Do not label this RC a verified
four-host stable release until those records exist.
